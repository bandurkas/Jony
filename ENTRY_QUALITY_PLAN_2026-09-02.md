1. **#78 ETH:P — контртрендовый override советника был легален по коду.**
   `RET_7D_THRESHOLD=1.0`, ret_7d=−1.08 → механика side-off. `decide_entry` пропускает
   пут против тренда, если chg_24h ≥ −0.5 и dist_7d_low ≥ 1.5 (было +2.15 / +2.36).
   Гард не смотрит: (a) страйк уже ITM на входе (2475 > спот 2464); (b) глубину
   даунтренда; (c) hold_h=120ч для тезиса «отскок выдохся», который живёт 24–48ч.
   Phase 7 грид (ret7d ∈ {0.5…999}) выбрал 1.0 → зона override = зона, где бэктест
   путы отверг. По advice.jsonl: 3 победы советника (#64/#67/#74) были ПО тренду; override n=1 (#78, минус).
2. **#77 BTC:P — trail не взвёлся при пике +28%: так и задумано.** Trail для
   механических позиций только в tight/lockdown (безусловный trail REJECTED 14.08),
   плюс `TRAIL_REQUIRE_ENDGAME=1` (≥70% hold и ≥25%). Не баг, но 120ч-путы отдают
   средний профит обратно — лever для отдельного теста, не для «включить».
3. **confidence=0.72 во всех трёх advisor-входах.** Порог для коллов 0.7 → модель
   подставляет число, чтобы пройти. Гейт по confidence не информативен.
4. **Советник цитирует свой трек-рекорд n=1** («ETH:C 1/1 win») как аргумент.
5. **Нет книжного ограничения**: два ITM-пута одновременно + колл, чистая long-delta.
   Self-lock fix 26.08 снял блокировку по tight на второй монете — осознанно, но
   заменяющего правила нет.
6. **Stale-posture gap** (handoff 02.09): советник умер при posture=normal → бот без
   защитного слоя, никто не узнает. Уже в бэклоге после go-live.
